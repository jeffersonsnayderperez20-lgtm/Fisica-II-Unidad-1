# CampoLab - Física II - Unidad 1

Autor: Jefferson Snayder Perez Culqui.

Simulador interactivo de electricidad, campo eléctrico y potencial, con vistas 2D y 3D y movimiento de una partícula.

## Abrir el simulador

https://jeffersonsnayderperez20-lgtm.github.io/Fisica-II-Unidad-1/

## Archivos

- **index.html**: aplicación compilada para abrir en el navegador, con sus recursos incluidos.
- **codigo-fuente.zip**: código original editable en React y TypeScript, organizado por módulos, con las 12 pruebas e instrucciones de instalación. Descarga y descomprime para revisar o modificar las fórmulas y la interfaz.

El HTML es una distribución compilada; la fuente mantenible está en el ZIP. No se necesitan claves de API. El informe y el manual se entregan por separado en Drive.

## Modelo

Ley de Coulomb y superposición en SI. Fuentes puntuales fijas; se excluyen 0,08 m alrededor de cargas no nulas. Contornos y superficies son aproximaciones de malla. Integración de partículas con una variante simétrica de Boris. Consulta las pruebas y los límites documentados en el código.
